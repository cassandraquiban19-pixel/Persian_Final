PERSIAN LETTER RECOGNITION — STANDALONE PROJECT
===============================================

This package is intended to work WITHOUT your old project folder. Extract this ZIP
into a NEW folder. It contains the Streamlit app, one consistent 32-class mapping,
dataset generator, TensorFlow training script, and requirements.

IMPORTANT LIMITATIONS
- The model file is not included because it must be trained on your local dataset.
- The dataset is generated locally; Arabic/Persian-capable fonts are required.
- The first MobileNetV2 training run may need internet access to download ImageNet weights.
- No source package can guarantee a 97% score. Generated-font test results do not
  prove handwritten-letter performance.

WINDOWS SETUP (PowerShell)
--------------------------
1. Install Python 3.11 (recommended) and check:
      py --version

2. Open PowerShell in the extracted folder (the folder containing app.py).

3. Create and activate a clean virtual environment:
      py -3.11 -m venv .venv
      .\\.venv\\Scripts\\Activate.ps1

   If activation is blocked for this session:
      Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
      .\\.venv\\Scripts\\Activate.ps1

4. Upgrade pip and install packages:
      python -m pip install --upgrade pip
      python -m pip install -r requirements.txt

5. Add at least THREE Arabic/Persian-capable .ttf/.otf fonts to the included
   fonts folder. Suggested fonts: Noto Naskh Arabic, Noto Sans Arabic, and Amiri.
   You can use legally obtained fonts from their official project sources.
   Windows Tahoma/Arial/Segoe UI may be detected automatically, but glyph coverage
   depends on your machine.

6. Generate the synthetic dataset:
      python generate_dataset.py

7. Train and evaluate:
      python train_model_tf.py

   This creates:
      model/persian_model.keras
      model/label_mapping.json
      evaluation/classification_report.json
      evaluation/confusion_matrix.csv
      evaluation/evaluation_summary.json
      evaluation/training_history.png

8. Launch the app:
      python -m streamlit run app.py

AUGMENTATION
------------
The training pipeline uses modest rotation, translation, zoom, contrast, and
brightness variation. Keras augmentation layers run during training and are not
randomly applied at inference. There are no horizontal/vertical flips because
they can alter Persian character identity. Mild blur/noise is included in
synthetic dataset generation, not applied randomly to the live prediction.

FOLDER STRUCTURE
----------------
app.py

README_FIRST.txt

TROUBLESHOOTING
---------------
- If "No module named streamlit/tensorflow": activate .venv and rerun
  python -m pip install -r requirements.txt
- If fonts are missing: add three valid Persian/Arabic .ttf/.otf files to fonts/.
- If TensorFlow cannot install, verify Python is 64-bit and use Python 3.11.
- If training is slow, reduce BATCH in train_model_tf.py from 16 to 8.
- Keep dataset/, model/, and evaluation/ inside this extracted project folder.
